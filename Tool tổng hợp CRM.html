Tool tổng hợp CRM
Tổng hợp – phân tích thương vụ / dự án sale đăng ký trên CRM

Kéo – thả file Excel CRM vào đây

File export Deals từ CRM (raw) hoặc file template chuẩn đã convert (.xlsx)

(để trống = lấy theo tên file, không có thì lấy hôm nay)
Xử lý 100% trên máy bạn – không cần internet, không gửi dữ liệu đi đâu.

1. Nạp file raw export từ CRM

Kéo – thả hoặc chọn file export.deals.report…xlsx. Tool nhận diện tự động file raw hay file template chuẩn.

2. Tự động convert sang template chuẩn

Chuẩn hoá tên KH, phân nhóm KH, xác định hãng, giá trị VND, deal size, tách deal nhiều hãng và gắn cờ chất lượng dữ liệu.

3. Tìm kiếm, lọc & phân tích

Lọc đồng thời theo sale, giai đoạn, trạng thái, giá trị, timeline, nhóm KH, hãng, reseller, cờ nhắc. Biểu đồ cập nhật theo bộ lọc.

4. Tải file chuẩn & xuất báo cáo Excel

Tải file template chuẩn sau convert và xuất báo cáo Tổng hợp CRM_ Tháng M.YYYY.xlsx nhiều sheet thống kê.
